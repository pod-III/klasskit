How to Use Path Board

Print A4 Board Games & Live Smartboard Play

1. Printable A4 Board Games

Type one prompt per line, pick a layout (Winding, Spiral, or Zig-Zag), and click HANDOUT for a crisp A4 board with cut-out paper tokens. Add | answer after any line to generate a numbered Teacher Key.

2. Live Smartboard / Projector Play

Hide the left sidebar, pick 2–4 teams, and roll the built-in die! Tokens hop automatically along the path, trigger bonus/go-back tiles, and open a big readable prompt card when a team lands on a space.
