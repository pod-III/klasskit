How to Use Interview Maker

Build a handout, then run a class mingle

1. Build the Handout

  • Start from a Starter Template or a Blank Sheet.
  • Click directly on the A4 preview to edit the title, instruction, column headers and any cell.
  • Use ← ✕ → above each column to reorder or delete it; ✕ at the end of a row deletes that row.
  • Turn on Row 1 as Example Row and fill it with a model answer, then add a Target Language box with the question and answer pattern.
  • Choose the handwriting space, then Print. All editing controls disappear from the printout.

2. Run the Mingle / Survey

  1. Model: act out the example row with a confident student.
  2. Drill: chorus the Ask / Answer pattern a few times.
  3. Mingle: everyone stands, interviews a classmate, writes the answer, and moves on. Each row is a different classmate.
  4. Report back: students share findings out loud ("Sarah's favourite food is…") or complete the Report-Back writing.

Tips

  • Find Someone Who: students may write each classmate's name only once, so they have to keep moving.
  • Give younger learners more Handwriting Space and fewer columns.
  • Switch to Landscape for 6–8 columns.
  • Save handouts to the library. A loaded saved handout auto-saves as you edit it.
