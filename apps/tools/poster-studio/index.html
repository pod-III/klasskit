Quick Guide

1. Simple vs Pro & 15 Blocks

Start in Simple Mode with 8 core blocks plus the More picker for all 15 modules. Switch to Pro Mode for all 15 dock buttons, custom grids, corkboard/chalkboard backgrounds, undo history, and tape pins.

2. Bulk Import & Quick Paste

Use Bulk Import in the top bar to copy an AI-ready outline template and generate a full poster in seconds. Inside block editors, use interactive row builders or switch to Quick Paste (even TSV/CSV tables!).

3. Print & Zen

Click any card to edit, drag the handle or use hover arrows to reorder, print as a wall handout, or launch Zen Mode to present full-screen.

4. Shortcuts

Ctrl+S saves immediately, Ctrl+Z / Ctrl+Y undo or redo block changes, and pressing Enter in row builders adds the next item.
